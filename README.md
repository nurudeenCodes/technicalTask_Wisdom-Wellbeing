# Resource Centre

A single-page application displaying wellbeing resources grouped by category.
Built with React, TypeScript, Vite and MUI, developed test-first with Vitest
and React Testing Library.

## Running locally

```bash
npm install
npm run dev
```

## Tests

```bash
npm run test:run   # single run
npm test           # watch mode
npx tsc --noEmit   # typecheck
```
